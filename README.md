# Quandel BD Hub

Shared business-development CRM and training system for Quandel Enterprises
(QCG, QES, PCS, JVS, PYR and the ENT parent).

- `SPEC.md` — full build outline (data model, screens, rules engine, training, phases)
- `CLAUDE.md` — working rules for Claude Code
- `prototype/bd-hub.html` — clickable team prototype, published at
  https://claude.ai/artifact/UFYEMekqpSiJC7joYGes5r (data lives in that artifact's shared store)
- `data/` — state rules and funding-program seeds, editable without code

The production app (Next.js + Prisma, per SPEC.md §12) is built phase by phase.
